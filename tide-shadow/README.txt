潮影双行 — 怪兽城堡与失落海岛

本地双人3D合作冒险。需要两名真人使用同一台电脑、同一键盘；左右独立分屏，镜头在角色后方。不是单人电脑伙伴模式，也不是网络联机。

开始玩
1. 直接双击「潮影双行.html」即可离线启动，无需安装、联网或账号。
2. 本机服务入口：http://127.0.0.1:8769/ （运行服务的电脑上有效；这是本机地址，不是公网链接。）
3. 推荐桌面 Chrome / Edge 等支持 WebGL 的浏览器，横向大窗口或全屏。手机与手柄不在本版支持范围。

玩家1 — 岚（左屏）
WASD：相对自己的镜头移动；X：跳跃。
Q / E：向左 / 向右转动自己的镜头。
左Shift：盾牌与诱饵之间切换。
左Ctrl：点按使用。盾牌保护3秒，近身盾击剥开重甲；诱饵吸引附近守卫8秒。最终风暴盾保护4秒，并能反击潮王的蓄力震波。

玩家2 — 烁（右屏）
方向键：相对自己的镜头移动；空格：跳跃。
逗号 / 句号：向左 / 向右转动自己的镜头。
Enter：点按射击或使用机关；不需要右Ctrl。数字键盘Enter和右Ctrl保留兼容。
Backspace：弓箭与望远镜之间切换，并已阻止浏览器后退。望远镜放大自己视角，使用后短暂标记更远处敌人；再次Backspace切回弓箭。

共同规则
靠近自己的橙色/青色机关，使用键优先互动。想举盾、投诱饵或射敌人时，离机关稍远一些。
弓箭自动选择射程内可见敌人；发射无需鼠标、也无需按住Ctrl移动。
镜头自动跟随各自角色位置，转镜键独立，不会因同伴走远而看不见自己。任务旁箭头与米数指向当前目标；路径可能需要绕过墙壁。
每个关键出口都要两人到齐。掉落或生命耗尽后自动在路标复活，已解机关保留。
Esc：暂停；右上角：全屏、音效开关。暂停中的「操作与音量」可调整音量、逐项重新绑定两套按键。
A仅在开场剧情跳过；正常游戏中仍是玩家1左移。Enter在菜单和剧情中不会发射。

八个连续区域
盐牢醒来 → 守卫长厅 → 齿轮断塔 → 黑潮追城 → 失落海岸 → 双月遗迹 → 风暴军械库 → 潮王苏醒。
包含相互开牢门、诱敌夺钥匙、拆警报、两次交换留守断桥、追逐清障、分头寻物、跨路线限时符文、三波重甲敌人与三阶段怪兽战。
每区另有一张可选航海日志碎页。暂停菜单中的「航海日志」可以阅读已收集内容；通关区域可重玩补全收集。
需要更多帮助时看同包「通关提示.txt」。不必先看攻略。

存档
独立本地存储键：tideborn.coop.v1。保存当前区域、解锁区域、已解机关、日志、音量和自定义键位。
位置和敌人即时生命值不跨刷新保存；继续时从本区起点开始，保留机关进度，战斗按当前波次/区域重新开始。
离线文件、本机网页、不同浏览器的存档相互独立。旧三款游戏与存档未修改。

范围
原创、全部几何模型自制的浏览器小游戏；不是《双人成行》或任何商业原作移植，也不具备同等体量。
画面为简化3D美术，敌人使用简单巡逻/追击AI。实际首次游玩时长因探索、沟通与战斗而异，未以真人全程计时作保证。
